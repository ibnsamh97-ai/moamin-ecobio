جامعة تكريت – كلية التربية للعلوم الصرفة – قسم علوم الحياة – تخصص التلوث والمعالجة البيئية

## ما الذي يقدمه الموقع؟

| القسم | ماذا يفعل |
|---|---|
| الرئيسية | كرة أرضية ثلاثية الأبعاد للعراق ودجلة والمحطات والأقمار، قراءات حية، وبطاقة بحث المشرفة |
| الرصد الفضائي الحي | قراءات 10 ملوثات لسبع محطات من Copernicus CAMS وصور أقمار NASA اليومية، تحديث كل 30 دقيقة |
| خريطة العينات | تحديد العينات بالضغط على صور فضائية عالية الدقة (Esri / Sentinel-2 / NASA) أو بـ GPS الهاتف، تسجيل النتائج والصور، فتح أي نقطة في خرائط Google، مشاركة برابط، تصدير GeoJSON وCSV واستيرادها |
| بحوث جامعة تكريت | نتائج منشورة حقيقية (منها بحث المشرفة عن بكتيريا دجلة في تكريت) بجداولها ورسومها ومراجعها، مع إرسالها للمختبر والحاسبات |
| مختبر المياه | WQI وHPI والمطابقة مع المواصفة العراقية 417 ونظام خبير للمعالجة، بعينات حقيقية من بحوث الجامعة |
| الحاسبات العلمية | 24 حاسبة: CCME WQI، HPI/HEI، العسرة، SAR و%Na وKR وMH وPI وRSC، Igeo وCF وEF وPLI وRI، المخاطر الصحية HQ وHI وCR، BOD وCOD وتشبع DO وونكلر والمواد الصلبة، التخفيف وتحضير المحاليل ومنحنى المعايرة، الأمونيا السامة، حركية التحلل، النمو الميكروبي، لانكماير وفرندلش، BCF وTF، نسبة الإزالة، تحويل وحدات الغازات، AQI، والإحصاء مع p-value |
| قراءة الصور | مؤشر لون الماء Forel-Ule من صورة الهاتف بطريقة علمية منشورة، مؤشرات تقريبية للطحالب والرواسب والرغوة والزيت، قراءة موقع الصورة من GPS، تفسير Gemini، واستخراج قيم ورقة نتائج المختبر آلياً |
| التحليل الذكي | تعلم آلي داخل المتصفح، كشف الشذوذ، الارتباط، اتجاه مصادر التلوث، تقرير Gemini |
| التقارير PDF | تقارير رسمية باسم المختبر والطالب والمشرف تتضمن الجداول والرسوم والصور والتوقيعات |
| ثلاثي الأبعاد | محاكاة دجلة، العالم المجهري، مكتبة الملوثات |
| المساعد الذكي | Gemini متخصص بالتلوث والمعالجة، يقرأ القراءات الحية وعيناتك وبحوث الجامعة |

### مبدأ البيانات الحقيقية
- لا يعرض الموقع أي أرقام وهمية: عند انقطاع الاتصال تظهر رسالة واضحة بدلاً من بيانات تقديرية.
- كل رقم في «بحوث جامعة تكريت» منقول من مصدره المنشور مع رابطه.
- البحوث لم تنشر إحداثيات المحطات، لذلك مواقعها على الخريطة تقريبية ومذكور ذلك بجانب كل بحث.

### إضافة بحث جديد لطلاب الجامعة
افتح `js/data-research.js` وانسخ أحد عناصر `ECO.RESEARCH` وعدّل بياناته (العنوان، الباحثون، المجلة، الرابط، الموقع التقريبي، النطاقات أو الجداول). يظهر البحث تلقائياً على الخريطة وفي القائمة وفي سياق المساعد الذكي.

## رفع الموقع على GitHub Pages (بدون برمجة)

1. ادخل إلى [github.com](https://github.com) وأنشئ حساباً إن لم يكن لديك.
2. اضغط **New repository**، سمّه مثلاً `ecobio-ai`، واجعله **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، ثم اسحب **كل محتويات** مجلد `EcoBio-AI` (الملف `index.html` والمجلدات `css` و`js` و`vendor` والملف `README.md`) إلى الصفحة، ثم اضغط **Commit changes**.
   - مهم: ارفع **محتويات** المجلد لا المجلد نفسه، حتى يكون `index.html` في الجذر.
4. ادخل **Settings → Pages**، واختر في **Source**: `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
5. بعد دقيقة إلى دقيقتين يظهر رابط موقعك بالشكل:
   `https://اسم-حسابك.github.io/ecobio-ai/`

> للتجربة على حاسوبك قبل الرفع: افتح `index.html` مباشرة بالمتصفح (Chrome أو Edge) وهو متصل بالإنترنت.

## تفعيل المساعد الذكي (Gemini)

1. ادخل إلى [Google AI Studio](https://aistudio.google.com/apikey) بحساب Google واضغط **Create API key**.
2. افتح موقعك، واضغط أيقونة الترس ⚙️ أعلى الصفحة، والصق المفتاح، ثم **حفظ واختبار الاتصال**.
3. إن ظهرت رسالة أن النموذج غير متاح، اضغط **جلب النماذج المتاحة** واختر نموذجاً من القائمة.

**أمان المفتاح:** المفتاح يُحفظ في متصفحك فقط ولا يُكتب في الكود. لا تضع المفتاح أبداً داخل ملفات المشروع على GitHub لأن أي شخص يستطيع رؤيته.
يُنصح أيضاً من [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials) بتقييد المفتاح بـ **HTTP referrers** على نطاق موقعك `https://اسم-حسابك.github.io/*`.

### كيف «تخصص» المساعد بموضوعك؟

لا يحتاج Gemini إلى تدريب جديد؛ التخصص يأتي من **تعليمات النظام** و**قاعدة المعرفة** في الملف `js/config.js`:

- `ECO.SYSTEM_PROMPT`: شخصية المساعد وقواعده.
- `ECO.KNOWLEDGE`: معلومات مرجعية يعتمد عليها. أضف إليها نتائج بحثك وقراءات مختبرك ومصادرك، وسيستخدمها المساعد في كل إجابة.
- `ECO.CHAT_SUGGESTIONS`: الأسئلة المقترحة.

## العينات على الهاتف
- اضغط «عينة في موقعي» واسمح للمتصفح بالوصول للموقع (يتطلب رابط https مثل GitHub Pages).
- العينات تُحفظ في متصفح الجهاز نفسه. لنقلها إلى جهاز آخر أو لمشرفك: «رابط مشاركة» أو «GeoJSON» ثم «استيراد».

## تعديل بياناتك

افتح `js/config.js` وعدّل:

```js
ECO.PROJECT = {
  student: "اسم الطالب",
  supervisor: "اسم المشرف",
  ...
};
```

ويمكنك من الملف نفسه إضافة محطات رصد (`ECO.STATIONS`)، أو تعديل الحدود القياسية للمياه (`ECO.WATER_PARAMS`)، أو طرق المعالجة (`ECO.TREATMENTS`).

## مصادر البيانات وحدود الدقة

- **جودة الهواء:** نموذج Copernicus Atmosphere Monitoring Service (CAMS) العالمي عبر [Open-Meteo](https://open-meteo.com/en/docs/air-quality-api)، بدقة 0.4° (نحو 45 كم) وتحديث كل 12 ساعة. هذه بيانات نموذج يدمج أرصاد الأقمار الصناعية، وتمثل المنطقة لا نقطة بعينها، ولا تغني عن محطات القياس الأرضية. الاستخدام مجاني للأغراض غير التجارية مع ذكر المصدر.
- **صور الأقمار الصناعية:** [NASA GIBS](https://www.earthdata.nasa.gov/engage/open-data-services-software/earthdata-developer-portal/gibs-api) (VIIRS، MODIS، OMI). بعض الطبقات تتأخر أياماً أو تحجبها الغيوم.
- **جودة المياه:** تُدخَل من التحليل المختبري؛ القيم التوضيحية في الموقع للتجربة فقط وليست قياسات حقيقية.
- **المحاكاة ثلاثية الأبعاد:** تعليمية، ونسب الإزالة فيها تقريبية.
- **قراءة الصور:** مؤشر Forel-Ule من صورة الهاتف تقريبي للفرز السريع ويتأثر بالإضاءة وإعدادات الكاميرا (Wang et al., 2021, Scientific Data).
- **الخرائط:** صور Esri World Imagery وSentinel-2 cloudless 2023 (EOX) خرائط أساس للتحديد الدقيق، وطبقة NASA GIBS اليومية لرؤية النهر في تاريخ معين.
